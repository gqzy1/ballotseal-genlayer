# BallotSeal scope

This implementation focuses on the chronological relationship between proposal revisions and prior acknowledgements. Its stateful contribution is the monotonic consent epoch, immutable version/confirmation history and independent five-dimensional material-change assessment. Generic voting, quorum and treasury execution are outside scope.

The restored V0.2 BallotSeal source was reused and audited. V0.3 adds immutable acknowledgement records, bounded explanations with quote grounding, parent text digests, exact input bounds and complete release documentation. No other project's source, design, branch or test result is used as implementation evidence. No worldwide novelty or uniqueness claim is made.
