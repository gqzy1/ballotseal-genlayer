# BallotSeal visual system

Graphite-blue surfaces, cool cyan integrity signals, restrained violet semantic accents and amber material-change signals. A custom geometric seal with intersecting context orbits introduces the product. Fine grids, monospace annotations, deliberate spacing and large editorial type provide identity without a trading dashboard or terminal aesthetic.

The complete interface covers onboarding, empty/custom proposal creation, two-column text comparison, safe character diff, per-dimension explanations/quotes, epoch transitions, explicit confirmation, chronological inspection and record verification/export. State labels always accompany color. The visual seal does not imply AI execution or a completed onchain transaction.

CSS geometric artwork and native SVG are authored for this product. No painting, brushwork or external image asset is used. Fonts are system-local, avoiding third-party font requests. Orbital breathing and result transitions respect prefers-reduced-motion.

See evidence/browser-acceptance.md for actual browser observations; CSS design intent is not itself proof of visual acceptance.
